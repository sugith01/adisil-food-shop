# 🍽️ ADISIL – Food Shop Landing Page

**ADISIL – Tradition on Every Plate**

ADISIL is a modern and responsive food shop landing page designed to showcase authentic and delicious food through a clean, attractive, and user-friendly interface.

The website combines a traditional South Indian food identity with a modern web design approach.

---

## 🌐 Live Website

🔗 https://sugith01.github.io/adisil-food-shop/

---

## ✨ Features

- 📱 Fully responsive design for mobile, tablet, and desktop
- 🏠 Modern hero section with food imagery
- 🍛 Food categories section
- ⭐ Popular and featured food items
- 📖 About ADISIL section
- 🎁 Special offers section
- 💬 Customer reviews
- 📞 Contact section
- 📧 Email contact using `mailto`
- 💬 WhatsApp contact integration
- 🍔 Food category filtering
- 📱 Responsive mobile navigation menu
- 🎨 Hover effects and CSS animations
- 🔝 Smooth navigation between sections
- ♿ Semantic HTML and accessible form elements

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic elements
- **CSS3** – Styling, responsive layout, animations and hover effects
- **JavaScript** – Interactive functionality and user interactions
- **Git & GitHub** – Version control and project hosting
- **GitHub Pages** – Website deployment

🧩 Website Sections

The landing page contains the following sections:

🧭 Navigation Bar

Provides navigation links to different sections of the website and includes a responsive mobile menu.

🍽️ Hero Section

Introduces ADISIL with a food image, brand message, description and call-to-action buttons.

🍛 Food Categories

Displays different food categories available at ADISIL.

⭐ Popular Foods

Showcases popular food items with images, descriptions and pricing.

📖 About Us

Introduces ADISIL and its food philosophy.

🎁 Special Offers

Displays promotional offers available for customers.

💬 Customer Reviews

Displays customer feedback and reviews.

📞 Contact

Provides contact information and a contact form for customers.

🔗 Footer

Contains copyright information, social media links and contact details.

📱 Responsive Design

The website is designed to work across different screen sizes:

📱 Mobile devices
📲 Tablets
💻 Laptops
🖥️ Desktop screens

CSS media queries, Flexbox and CSS Grid are used to create the responsive layout.

🎨 Design

The design combines:

🌿 Traditional South Indian food aesthetics
🟢 Deep green tones
🟡 Warm golden accents
🤍 Cream and light backgrounds
🍂 Earthy food-inspired colors
✨ Modern typography
🎞️ Smooth CSS animations

The banana leaf visual identity represents the traditional South Indian dining experience.

🚀 Deployment

This project is deployed using GitHub Pages.

To deploy the project:

Push the project to GitHub.
Open the repository Settings.
Select Pages.
Choose Deploy from a branch.
Select the main branch.
Select / (root).
Click Save.

The website will then be available through the GitHub Pages URL.
